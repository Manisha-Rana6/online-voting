# User Registration and Dashboard Web App

This is a simple web application that allows users to register and view a dashboard. It includes HTML, CSS, PHP, and MySQL components.

## 📁 Project Structure

- `index.html` - Landing page of the site.
- `register.html` - User registration form (frontend).
- `register.php` - Handles form submissions and user registration logic.
- `connect.php` - Connects the application to a MySQL database.
- `dashboard.php` - Displays user dashboard after successful login/registration.
- `style.css` - Styling for the web pages.
- `README.md` - Project overview and documentation.

## 🛠️ Technologies Used

- HTML5
- CSS3
- PHP
- MySQL

## ⚙️ Setup Instructions

1. Clone or download this repository.
2. Set up a local server using XAMPP, WAMP, or similar.
3. Create a MySQL database and update the credentials in `connect.php`.
4. Place all files in your server's root directory (e.g., `htdocs` for XAMPP).
5. Open `index.html` in your browser to get started.

## 🧾 Features

- User registration form
- Backend processing with PHP
- Database connection and user data storage
- Basic dashboard display after registration
